# Spin-Game
Wisdomania Energy
✨ WISDOMANIA PRO

Align. Grow. Enjoy. Balance Life

Wisdomania Pro is a gamified web application that blends culture, intuition, and entertainment into a rewarding user experience. Users can spin, earn coins, check oracle insights, and calculate traditional market days — all in one platform.

---

🚀 Features

🎡 Spin & Win

- Cost: 20 coins per spin
- Rewards include:
  - 0 coins (high probability)
  - 5, 10, 20, 50 coins
- Integrated sound effects (spin + win)

---

🔮 Oracle System

- Ask questions and receive insight-based responses
- Costs 15 coins per question
- Premium users unlock extended responses (300+)

---

📅 Market Day Calculator

- Based on Igbo cycle:
  - Orie → Afor → Nkwo → Eke
- Base reference:
  - 01/01/2026 = Orie
- Users input a date to calculate alignment

---

🪙 Coin Economy

- Earn coins via:
  - Daily rewards (+20)
  - Spin winnings
- Spend coins on:
  - Spins
  - Oracle questions
  - Premium upgrade

---

👑 Premium Upgrade

- Cost: 500 coins
- Benefits:
  - Full oracle access
  - Enhanced experience

---

💰 Monetization

- Ad integration (Adsterra)
- Coin purchase system (external payment link)
- Premium upgrade conversion

📦 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage (for user data persistence)

   - "spin.mp3"
   - "win.mp3"

4. Open in browser OR deploy online
